Slowly working on Daicon 1.5 🛠

The second-version sorting system is already done and it's miles ahead of the old one. I've improved and optimized a lot of things on the technical side. Also added new nodes — RigidDaicon and DaiconShadow (not a dynamic one, more of a drop shape). I'm currently polishing the latter.

#daicon #gamedev
Release! Daicon Version 1.0

Daicon is a Godot plugin for building 2.5D games.

It works by using 3D space to move two-dimensional objects, simulating three-dimensional environmental depth within a 2D dimension.

The addon gives developers a set of new nodes and extra tools that combine 3D and 2D capabilities at once.
